# Contributing to Fuz

Fuz is an intended nonprofit that stewards a collection of open source free software projects.
Everyone is welcome to participate in the Fuz community spaces:

- contributions to Fuz take many forms in public:
  - discussions on GitHub - see each repo and
    the [fuzdev org discussions](https://github.com/orgs/fuzdev/discussions)
  - issues (bugs)
  - PRs are accepted from people who know what they're doing -
    design input in discussions is generally more valued by the maintainers than code changes
  - Bluesky (TODO create fuz.dev account)
- the Fuz community seeks quality and clarity
  - LLMs/AI tool usage is acceptable; disclose usage when appropriate
    (this is always a judgment call, when in doubt please err on the side of transparency)
  - be aware slop causes frowns and reputational damage
  - be aware every action you take in public spaces costs people's time and attention
- please be kind and respectful and honest; creativity and thoughtfulness are held in high regard
