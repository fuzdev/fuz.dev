the Fuz stack

Fuz is a free software stack designed for human agency: it provides tools and libraries in TypeScript, CSS, Svelte, and Rust, building on open web and native foundations. It bakes in some opinions but is designed for modularity, so you can use a single piece or whichever parts fit your project. All of the code on GitHub is licensed with the public-domain-equivalent 0BSD. For the story behind it, read the intro post.

Everything is pre-1.0 and changes without deprecation. Each piece below is marked by where it stands:

  • ready usable in production; pre-1.0, so follow the changesets
  • early pre-alpha and under active construction; expect gaps
  • experimental exploring a direction; may change shape or not survive

and what it's made of:

  • TypeScript TypeScript
  • Svelte Svelte and SvelteKit
  • CSS CSS
  • Rust Rust
  • WASM WASM, compiled from Rust

apps and sites

What gets built on the stack, starting with the template and the apps Fuz runs itself.

  • fuz_template ready TypeScriptSvelteRust

    starter template for SvelteKit web apps, Rust native tools, or both · repo

  • zzz experimental TypeScriptSvelteRust

    software garage for power users and devs

  • zervo experimental Rust

    native Zzz window host using Servo

  • fuz_forge early RustSvelte

    personal-scale forge for self-hosting git repos, signed releases, and files

fullstack

A backend in TypeScript or Rust or both, sharing one server pattern for auth, sessions, database, and APIs and one data model of cells, facts, and actions, with SvelteKit in front and deploys local-first or to the cloud.

  • fuz_app early TypeScript

    fullstack app library: auth, sessions, accounts, database, and middleware for SvelteKit and Hono · repo

  • fuz early Rust

    the fuz CLI, fuzd daemon, and the Rust crates beneath the stack's servers

frontend

Semantic HTML that looks good by default, Svelte components and theming, syntax styling, and a markdown dialect for docs and untrusted content.

  • fuz_css ready CSS

    semantic-first CSS framework and design system · repo

  • fuz_ui ready Svelte

    Svelte component library and frontend helpers · repo

  • fuz_code ready TypeScript

    syntax styler for TypeScript, Svelte, Markdown, and more · repo

  • mdz ready TypeScript

    strict markdown dialect built for streaming, web authoring, docs, and untrusted content · repo

  • fuz_blog ready TypeScriptSvelte

    blog software from scratch with SvelteKit · repo

tooling

Run tasks, parse and format in the terminal or editor, analyze code, and manage many repos, with an agent skill that teaches the conventions.

  • gro ready TypeScriptRust

    task runner, codegen, and checks for web projects, becoming its own V8 runtime

  • tsv ready Rust

    precise language tools for TypeScript, JS, CSS, and Svelte: parser and formatter · repo

  • tsv-format ready WASMTypeScript

    VS Code extension: format on save, powered by tsv

  • svelte-docinfo ready TypeScript

    static analysis for TypeScript and Svelte 5, feeding docs and tools · repo

  • fuz_repos ready TypeScriptRust

    multi-repo management: publish cascade, dashboard, and the repos tool · repo

  • fuz-stack ready

    the agent skill that teaches the conventions of the stack · repo

  • corpora ready

    pinned snapshot of real-world code for language-tool gates and benchmarks

utilities

Small building blocks: helpers JS lacks, types, async, schemas, and hashing.

  • fuz_util ready TypeScript

    utility belt for JS: helpers, types, async, and logging · repo

  • fuz_schema ready TypeScriptRust

    performance-focused Standard Schema library for JS, with a Rust side that validates JSON text · repo

  • blake3 ready RustWASM

    BLAKE3 hashing compiled to WASM

native and data

System tools in Rust: set up and deploy to Linux machines, and an embeddable Postgres-compatible engine that makes tests fast today and aims to go places the elephant can't fit.

  • zap early TypeScriptRust

    convergent machine-state management: set up and ship to Linux machines from TypeScript · repo

  • pglet early Rust

    small embeddable Postgres-compatible engine, native and WASM
